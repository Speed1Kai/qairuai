# ЖИ қолдану туралы декларация

Final Protocol жобасында ЖИ құралдары бағдарламаны әзірлеуге, түсіндіруге және тексеруге көмек ретінде қолданылды. Бұл құжат құралдармен орындалған жұмыстардың сипатын ашық көрсетеді.

| Құрал | Қолданылуы |
|---|---|
| Codex және ChatGPT | Жоба идеясын нақтылау, C++ және Python кодын дайындау, Blueprint авторлау, диагностика, тест сценарийлері және құжаттама. |
| Gemini | Қала, интерфейс және нысандар үшін көрнекі референстер, трейлердің кейбір материалдары. |
| Blender скрипттері | Модельдер мен көріністерді құрастыруды автоматтандыру. |
| ElevenLabs | Жобамен жұмыс барысында трейлер дауыстарын дайындау. |

## Өнімдегі үш оқу әдісі

A*, CSP және Омеганың реактивті ережелері ойынның жергілікті логикасында іске асырылған. Олардың кірістері, нәтижелері және тексерулері техникалық есепте берілген. Қолданылған генеративті құралдар оқу әдістерінің осы іске асырылуына қосымша көмек болды.

## Тексеру және жауапкершілік

Құрал жасаған код үшін автоматтандырылған есептеу, Blueprint, PIE және Windows іске қосу тексерулері орындалды. Дәлелдер GitHub-та сақталған. Команда мүшелері қорғауда алгоритмдерді өздері түсіндіріп, мәлімдеменің мазмұнын оқып растауы тиіс.

Бұл құжат әзірлеу жазбалары негізінде дайындалды. Әр қатысушының құжатты қабылдауы мен жеке үлесі қол қою арқылы бөлек расталады.
